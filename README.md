# Cutie_Calc
A fun, cute interactive themed calculator with two pages 1st page is the home page where you get the options to stay on the home page or go to the Calc page to have your calculations done but on that same page their are two surprise for the user to have a little fun.

## Why use this Calculator?
One should use this because it's just better than a traditional calculator. The theme is different, the colors, and other than calculations there are two more feaures for the user,
1st one if the user wants he can know a maths fact and 
the 2nd one is if he/she wants he can write something about maths x just a fun element.
